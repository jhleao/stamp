Stamp

Stamp helps technical and non-technical collaborators generate fully in-brand documents and slide decks.

Use Google Drive like a Git repository. Create your own components with Preact and Tailwind. Agent friendly.

Screenshots:

> brew install jhleao/tap/stamp
> stamp tutorial

Stamp requests access only to the Google Drive files you select so it can clone and synchronize a Stamp project and update shared rendered documents. It cannot access unrelated Drive files.
