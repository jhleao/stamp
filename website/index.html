Local-first document work

Documents with source.

Stamp turns readable Markdown, TSX components, and Tailwind themes into polished PDFs. Work on ordinary files, hand the folder to an agent, and share complete revisions through Google Drive.

Install StampView the source ↗

One command to install.

Signed and notarized for macOS. Homebrew keeps it current.

brew install jhleao/tap/stamp

A short loop.

Drive holds the shared revision. Your machine holds the working copy. Stamp keeps the boundary visible.

01 / Pull

Start from what is shared.

Choose a Stamp project in Drive and bring its complete source and theme to your machine.

02 / Make

Edit files, not a format.

Write directly in Studio or ask an agent to work in the same local folder. Preview before publishing.

03 / Push

Publish one coherent revision.

Stamp renders every output, checks remote drift, and updates the shared project without silent overwrites.
