Stamp

Privacy policy.

Stamp is a local-first desktop tool. This policy explains what it accesses, where processing happens, and how you remain in control.

Google Drive access

Stamp requests Google’s per-file drive.file permission. This lets Stamp create Drive files and access only files that it created or that you explicitly share with Stamp through Google Picker.

A project contains its canonical archive, retained Drive revisions, a Current folder, generated PDF outputs, file identifiers, names, revision identifiers, and Stamp-specific metadata. When collaborating on an existing project, you may need to select both its folder and canonical .stamp archive so Google can authorize those files for Stamp.

Stamp cannot use this permission to inspect unrelated Drive content.

How data is processed

Source files, themes, components, assets, and generated documents are downloaded to your computer and processed locally. Stamp does not operate a hosted document service. Your Google Drive content is not transmitted to or stored on a Stamp-operated server.

Google OAuth access and refresh tokens are stored in the operating system’s secure credential store. On macOS, Stamp uses Keychain.

Sharing and use

Stamp does not sell Google user data, use it for advertising, or share it with data brokers. Data is sent to Google only as needed to authenticate, read or update the selected project, preserve revisions, and mirror generated outputs.

Stamp’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Telemetry and updates

Stamp has no product analytics, advertising trackers, or hosted telemetry. The CLI may make a daily request to GitHub Releases to check whether a newer version exists. That result is cached locally. Set STAMP_NO_UPDATE_CHECK=1 to disable automatic checks.

This website uses no analytics, cookies, local storage, or tracking scripts. Cloudflare delivers the static files and may process ordinary network logs under its own policies.

Retention and deletion

Local project files remain until you delete them. Drive projects and revisions remain under your Google Drive account and its retention rules until an authorized user removes them.

stamp logout removes Stamp’s locally stored Google credential. You can also revoke Stamp in your Google Account connections. Uninstalling Stamp does not delete local project folders or Drive content automatically.

Security

Stamp uses OAuth 2.0 with PKCE, stores credentials in the operating system credential store, and publishes signed releases with checksums. No software can guarantee absolute security; report suspected vulnerabilities privately through the contact route on the support page.

Changes and contact

Material changes will be published here with a revised effective date. For privacy questions or deletion guidance, use Stamp support.
